# Builtechraft

[![Documentación de Builtechraft](src/assets/00.avif)](https://builtechraftwiki.tarquitet.com/)

Builtechraft es una comunidad privada de Minecraft enfocada en la creatividad, la exploración y la colaboración. Este repositorio contiene la documentación pública del proyecto, incluyendo guías, información del servidor, recursos de soporte y ayuda para nuevos jugadores.

## ¿Qué es Builtechraft?

Builtechraft se centra en una experiencia de servidor amable y organizada con:

- Juego en Creative y Survival dentro de una comunidad privada
- Acceso controlado mediante whitelist, con soporte a través de Discord y coordinación del staff
- Funciones útiles como waypoints, mapa web, cabezas decorativas y mods opcionales
- Documentación clara para que los jugadores encuentren respuestas rápidamente y se incorporen con confianza

## Sobre este proyecto de documentación

Esta documentación fue migrada desde GitBook hacia una solución propia basada en Astro y Starlight. La transición se realizó para tener mayor control sobre la estructura, el diseño y el mantenimiento del contenido, además de evitar las limitaciones que fueron complicando la experiencia con GitBook.

Los beneficios de esta nueva base son:

- Más libertad para organizar el contenido de forma clara y escalable
- Una experiencia de documentación más moderna y cómoda de navegar
- Mantenimiento más simple a largo plazo
- Despliegues automáticos para publicar cambios de forma más rápida
- Un solo dominio para integrar el sitio público y la documentación de manera coherente

## Desarrollo

Este sitio de documentación está construido con Astro y Starlight.

- Instalar dependencias: `npm install`
- Iniciar la vista previa local: `npm run dev`
- Construir para producción: `npm run build`

Los despliegues se automatizan desde este repositorio y el sitio público junto con la documentación comparten el mismo ecosistema de dominio para una experiencia más consistente.
