# Builtechraft

Builtechraft es una comunidad privada de Minecraft enfocada en la creatividad, la exploración y la colaboración. Este repositorio contiene la documentación pública del proyecto, incluyendo guías, información del servidor, recursos de soporte y ayuda para nuevos jugadores.

## De qué trata este proyecto

Builtechraft se centra en una experiencia de servidor amable y organizada con:

- Juego en Creative y Survival dentro de una comunidad privada
- Acceso controlado mediante whitelist, con soporte a través de Discord y coordinación del staff
- Funciones útiles como waypoints, mapa web, cabezas decorativas y mods opcionales
- Documentación clara para que los jugadores encuentren respuestas rápidamente y se incorporen con confianza

## Desarrollo

Este sitio de documentación está construido con Astro y Starlight.

- Instalar dependencias: `npm install`
- Iniciar la vista previa local: `npm run dev`
- Construir para producción: `npm run build`
