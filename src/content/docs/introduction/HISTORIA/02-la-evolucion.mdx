El proyecto probó distintos tipos de servidor. [Paper](https://papermc.io/) ofrecía gran personalización mediante plugins. [LeavesMC](https://leavesmc.org/) aportaba funciones técnicas, como Litematica, para compensar cambios de Spigot y Paper sobre Vanilla.

En este proceso, se integraron plugins como [PySpigot](https://github.com/magicmq/pyspigot), que permite usar Python en Spigot, y [Conditional Events](https://www.spigotmc.org/resources/conditionalevents-custom-actions-for-specific-events-1-8-1-21-11.82271/), que habilita eventos complejos. También se implementó un sistema que permite automatizar la instalación y actualizacion de plugins y mods llamado [AutoPlug](https://autoplug.one/).

Tras estas pruebas, Builtechraft adoptó [Fabric](https://fabricmc.net/). Sus mods permiten optimizar el servidor y gestionar bots, carga de chunks y copias de seguridad.

Así, Builtechraft evolucionó de **Vanilla** a **Semi-Vanilla**, con datapacks que añaden mejoras puntuales.
